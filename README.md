# ML Star Constellation NASA Classification Project

## 📌 Project Overview
This project aims to build an automated machine learning system capable of identifying and classifying astronomical objects (such as Stars, Galaxies, and Quasars) or specific star constellations using numerical telescope and sky-survey features. This can be applied to automated astronomical cataloging, astrophysical research, or space data analysis.

## 📂 Dataset Information
- **Source:** Kaggle - Star Classification by Deepak Singh (SDSS dataset)
- **Size:** 100,000+ astronomical observations.
- **Classes:** 3 main categories (STAR, GALAXY, QUASAR) or specific constellations depending on the mapping.
- **Features:** Right ascension, declination, photometric bands (u, g, r, i, z), redshift, etc.

## 🛠️ Approaches
This repository documents two distinct methodologies for achieving the project goal:

1. **No-Code Approach:** Leveraging AutoML platforms and GUI-based tools for rapid prototyping and deployment.
2. **Code-Based Approach:** A full Python lifecycle using Scikit-Learn, covering scoping, cleaning, EDA, modeling, and evaluation.

## 🚀 Getting Started
1. Download the dataset from Kaggle using the Kaggle API or manual download.
2. Extract the contents and place the CSV (`Star_classification.csv`) into your working directory.
3. Follow the steps in either the No-Code or Code-Based approach documents.
